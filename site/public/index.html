Build with tGBP

tGBP is Tokenised GBP, a British pound stablecoin. Each token is backed one to one by cash and cash equivalents. It runs on Ethereum, Base, Solana and other chains, with 18 decimals on EVM chains and 9 on Solana.

Start with the quickstart. It takes a clean machine to a confirmed test tGBP transfer on Base Sepolia in about 15 minutes.

Developer kit

@tgbp/kit is an open-source TypeScript kit under the MIT licence.

ModuleWhat it does
@tgbp/kit The token registry: every tGBP deployment, its address and decimals. Amount parsing and formatting.
@tgbp/kit/evm Balances, transfers and incoming-transfer watchers on EVM chains, built on viem.
@tgbp/kit/solana The same helpers on Solana, built on @solana/kit.
@tgbp/kit/api A typed client for the tGBP API's mint, redeem, swap and balance endpoints. It sends idempotency keys and retries only what is safe to repeat. Needs the API key you get at onboarding.

The README documents every helper and error code.

API reference

Business clients mint and redeem tGBP through the tGBP API. Its full reference is at mint.tgbp.io/api-reference, behind your tGBP account login.

@tgbp/kit/api wraps those endpoints. Staging keys work against the sandbox, which runs on testnets and simulates bank transfers. The README shows a mint, a redemption and a swap quote.

Community

Ask questions and request test tGBP in the tGBP developers Telegram group.

Admins never DM first. No tGBP admin will message you before you message them, and none will ask for a private key, a seed phrase or a payment. Anyone who does is an impostor: block and report them.
