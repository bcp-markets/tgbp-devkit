Release notes

For AI agents. This page is also Markdown, at /releases.md, and llms.txt lists every page. To act on tGBP, install the tgbp-mcp MCP server and the agent skills from @bcptechnologies/tgbp-kit: the README has the config. Start on testnet: Base Sepolia, test tGBP from the faucet, and the API sandbox, the server's default. Act through the server and its spend policy, and never ask for the API key or the wallet key.

Each release of @bcptechnologies/tgbp-kit on npm and tgbp-kit on PyPI, newest first. Dates are the day the release reached the registry.
